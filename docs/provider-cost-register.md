# Provider cost register

Required by `architecture.md` §23 and `CLAUDE.md` (€0 development budget). Every external service gets a row **before** it is provisioned. Re-check before each deployment and whenever pricing changes. If a service needs a payment card, billing activation, a paid trial or has automatic overage charges, stop and ask the owner.

S01 (monorepo bootstrap) uses only open-source packages from the npm registry and provisions no service.

S02 (CI) uses GitHub Actions within the free quota and the open-source gitleaks CLI (MIT licence), downloaded from its GitHub release with a pinned checksum. GitHub's own secret scanning and branch protection are not free for private repositories and are not used (see `docs/github-setup.md`). A CI run uses roughly 10 to 15 billed minutes, because each of the five or six jobs is rounded up to whole minutes, so the free quota covers well over a hundred runs a month.
